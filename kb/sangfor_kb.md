# [场景] AF防火墙 管理口不通
关键词: 管理口, ping不通, MGMT, eth0, 管理地址, STAT灯
1. 物理层：查看管理口 Link/ACT 灯与对端交换机端口，必要时换网线/换端口/确认 VLAN 放通管理网段
2. 地址配置：管理口默认常为 10.251.251.251/24（eth0），用同网段 PC 直连 ping 测试；IP 冲突或未配置则进控制台重配
3. 系统状态：STAT 灯常亮绿 = 系统正常启动，可排除硬件故障；ALARM 常亮红需查硬件告警
4. 管理通道：确认是否开启 ping 响应（Web 控制台或 CLI 策略）、管理口是否绑定独立 VRF/专用 VLAN
5. 旁路/串接部署均不影响管理通道；串接时管理口仍走独立管理网

# [场景] AF防火墙 安全策略与业务不通
关键词: 安全策略, 业务不通, 拒绝, 放通, 策略命中, 应用过滤
1. 先查命中：在「策略分析/会话」中确认流量命中了哪条策略（拒绝/允许/默认丢弃）
2. 五元组核对：源/目的地址对象、端口、应用识别是否与业务实际一致
3. 常见原因：地址对象配置过窄、未放通回程路由、NAT 策略漏配、安全域（zone）归属错误
4. 变更后务必清会话（清除该五元组会话表）再验证，旧会话会残留旧策略结果

# [场景] 设备上架加电
关键词: 上架, 加电, 装机, 硬件, 到货, STAT灯, ALARM
1. 核对设备型号、S/N 与到货清单，确认电源/风扇/光模块齐备
2. 机柜固定并规范接地，检查供电电压后加电，观察 STAT/ALARM 指示灯
3. Console 或管理口登录，核对系统版本、授权与硬盘 RAID 状态
4. 按拓扑预配置管理地址与路由，先跑基线再接入业务

# [场景] 割接切换
关键词: 割接, 切换, 迁移, 替换, 回退, 串接, 旁路
1. 割接前：导出并备份新旧设备配置，梳理接口/VLAN/路由/策略映射表
2. 明确回退点与回退负责人，准备串接旁路/回退命令清单
3. 割接中：按「先旁路、后串接」顺序切换，逐段验证业务连通与会话保持
4. 割接后：持续观察 30 分钟流量曲线与安全日志，确认无异常再收尾
5. 长连接业务（如 ASBF/数据库）注意会话保持与超时参数在新旧设备上保持一致

# [场景] IPSec VPN 协商失败
关键词: vpn, ipsec, ike, 隧道, 协商, no proposal chosen, nat-t
1. 确认两端协商阶段：IKE 提议（加密/认证算法、DH 组）是否一致
2. 检查第二阶段感兴趣流（Proxy ID/保护网段）是否完全镜像
3. 排查 NAT 环境下的 NAT-T 与 UDP 4500 端口放行情况
4. 抓包查看 ISAKMP/IPSec 报文定位卡在哪个阶段

# [场景] 链路丢包与延迟
关键词: 丢包, 延迟, 变慢, 卡顿, 中断, 掉线, crc
1. 先分段定位：终端—网关—出口—对端逐跳 ping 结合大包测试
2. 查看接口错包/CRC 计数与光衰，排除物理层问题
3. 确认是否命中限速/流控策略或会话数达到上限
4. 在路径关键节点抓包对比，确定丢包发生段

# [场景] AC 上网行为管理
关键词: ac, 上网行为, 认证, 流控, 审计, 上网慢, 弹不出认证
1. 认证问题：确认认证方式（Portal/单点登录/免认证）与用户组匹配，未认证用户命中默认动作
2. 流控：检查流量管理通道带宽配额与保障通道优先级，是否被限速策略命中
3. 审计：确认审计策略应用范围与日志服务器存储空间
4. 常见：SSL 加密流量未被识别，需开启对应应用识别库并升级特征库

# [场景] AD 应用交付
关键词: ad, 应用交付, 负载均衡, 会话保持, 健康检查, 链路负载
1. 会话保持：确认会话保持方法（源IP/COOKIE/插入）与业务类型匹配，超时时间与业务一致
2. 健康检查：检查真实服务（real server）健康检查阈值，异常节点会被剔除
3. 链路负载：多出口场景确认出接口选择策略与探测状态
4. 常见：调度后业务异常多为会话保持缺失或服务端口配置错误

# [场景] EDR 终端安全
关键词: edr, 终端, 病毒, 查杀, 离线, 信任区, 勒索
1. 终端离线：检查终端与平台通信端口（默认 4482/54231）与证书信任
2. 误报处理：将业务文件加入信任区并上报平台分析，勿直接关闭防护
3. 勒索防护：确认勒索诱捕与主动防御开关已启用，配合定时全盘查杀
4. 常见：终端代理配置错误导致升级失败，检查升级服务器地址与代理设置

# [场景] 无线 AP 掉线
关键词: 无线, ap, capwap, 掉线, 漫游, 信道, 重连
1. CAPWAP 隧道：确认 AP 与 AC 间 UDP 5246/5247 放通，AC 地址发现方式（DHCP Option 43/DNS/静态）
2. 掉线重连：检查 AP 供电（PoE 功率不足会重启）、信道干扰与邻频冲突
3. 漫游：跨 AC 漫游需配置漫游组；终端漫游丢包多因信号强度与认证超时
4. 常见：AP 版本与 AC 版本不匹配导致反复上线，需升级对齐

# [场景] 日常巡检与备份
关键词: 巡检, 备份, 配置导出, 授权, 版本升级, 例行
1. 例行备份：每周导出配置文件与授权文件，异机保存；大版本升级前全量备份
2. 巡检项：CPU/内存/会话数基线、接口错包、安全日志告警、特征库/授权到期时间
3. 升级原则：先在备机/低峰期验证，确认回退方案后再升级生产
4. 日志留存：重要告警接入日志平台，保留 ≥90 天便于复盘
