Core Capabilities

五大能力，覆盖交付全流程

从网络透视到知识沉淀，每个环节都为“现场交付”而生。

灵犀测速 SPEEDLENS

一键全链路测速：握手、延迟、突发上下行一次测完，全程实时速率曲线 + 全链路透视 + 分段时延逐跳采样。

优势：AI 智能诊断根因 + 全链路透视，快速定位网络瓶颈。

内网感知 NETSENSE

接入客户内网即感知：实测本机接入方式（Wi-Fi / 有线）、网关与网段，真实 ping 扫描在线设备，自动生成拓扑、网段 / VLAN 表、设备清单。

优势：打印机自动标记 + 深信服设备建模给出部署建议，支持 Mermaid / JSON / PNG 导出。

随心记录 悬浮白板

全站右下角悬浮球，任意页面一键唤起：自由绘制、点击即打字，还能把当前页面截图插入画板做标注。

优势：内容自动保存本地，一键导出 PNG，实施灵感不丢失。

故障诊断助手 AI ASSISTANT

对话式排查深信服设备实施故障：整机上架、割接切换、VPN 组网、链路质量、无线漫游……基于 FastGPT 故障诊断知识库，深度思考后输出结构化排查清单。

优势：深信服场景专属 + 结构化排查路径，可直接粘贴日志分析。

案例复盘 AI REPORT

把项目过程讲给灵犀听，AI 自动生成结构化复盘报告：过程时间线、关键问题与根因、方法论提炼、风险与改进项。

优势：一键生成，可编辑并导出 Word / PDF，团队可复用。

Why CyberNWT

为什么是我们

不是又一个工具箱，而是为“交付现场”重新设计的作战终端。

01

免安装 · 即装即跑

双击 CyberNWT.exe 即起（自带 Python 运行环境，目标电脑无需装任何东西），后端纯标准库（HTTP + SQLite），不需联网拉包。

02

实测 + 建模 双引擎

ICMP / ARP / OUI / 端口指纹真实探针感知现场网络，支持声明深信服设备生成规划节点并给出施工部署建议，实测与规划虚实分明。

03

AI 可真可演

演示模式内置规则模板直接开演；对接 FastGPT 平台，搭载故障诊断 + 设备部署双知识库，即切换为真实大模型回答，平滑升级。

04

数据不出网

密码 PBKDF2-SHA256（12 万次迭代 + 随机盐）加密存储，演示模式数据全程留在本机；默认仅本机访问，需要局域网共享时再放行 8642 端口。

05

全域悬浮记录

任意页面一键唤起白板，捕捉实施灵感与截图标注，内容自动存本地。

06

智能诊断解读

测速结束即给出结果解读与瓶颈分析，无需专业知识也能看懂现场网络状况。
