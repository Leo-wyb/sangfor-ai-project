内网感知NETSENSE◌ 接入方式未知 —— 点击「开始感知」

工程师笔记本接入客户内网（网线 / Wi-Fi 均可），真实 ping 扫描网段、识别在线终端与打印机（自动标记），生成实测拓扑图 + 深信服设备部署位置建议，告别“听客户描述 + 手动画拓扑”。

① 本机网卡探测 ② 网关 / 网段识别 ③ 网络设备感知 ④ 设备指纹识别 ⑤ 拓扑与建议生成

部署规划 DEPLOY PLAN

本次交付要上架 / 部署哪些深信服设备？选型后在「期望的部署模式与功能」里填写该台的要求，点「＋添加一台」逐台加入（可加多台）；感知时会按设备特性在拓扑上建模、找准部署位置并给出针对性建议。不添加则默认按一台 AF 规划。
注意：为方便使用者，建议打开顶部《使用手册》进行对应视频播放，以免无法正确使用功能，感谢。
⚠ 当前仅探测本机接入 VLAN / 网段：客户内网普遍多 VLAN，其他 VLAN 的设备 ping / ARP 全部探测不到，拓扑会缺一块。可在下方手动补充其他网段，或多网卡时自动批量扫描。
填写交换机 IP 和 SNMP 团体字（交换机上开启了 SNMP 时），可读出真实物理链路；不填则连线按逻辑推演绘制。

网络拓扑图 TOPOLOGY含实测数据

绿色描边 = 实测节点 紫色描边 = 实测打印机 橙色虚线 = 深信服规划部署 青色描边 = 手动录入设备

① 尚未感知 —— 接入客户内网后点击右上角「开始感知」。
支持 Wi-Fi 接入感知，无需额外接网线；感知基于 ICMP ping + ARP + 端口指纹，禁 ping 设备可能未列出。

② 支持导入已有拓扑 —— 点击右上角「已有拓扑」，.topo 文件或图片均可；图片可作底图描点，也可自动建模为原生拓扑。

③ 支持从零开始搭建拓扑 —— 点击左上角「工具栏」展开工具，打开「添加拓扑」设备栏点选设备直接上图。
